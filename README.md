# 📋 TaskManager — TaskFlow

A modern, responsive task management dashboard built with **HTML, CSS, and JavaScript**. Organize your daily activities, track your progress, and stay focused with a clean and intuitive interface.

## ✨ Features

- **Task Management (CRUD):** Create, view, edit, and delete tasks.
- **Task Categories:** Organize tasks into Work, Personal, and Study categories.
- **Task Status Tracking:** View all tasks, active tasks, and completed tasks.
- **Search Tasks:** Quickly find tasks by title, description, or category.
- **Sorting:** Sort tasks by recently created, task name, or due date.
- **Due Dates:** Set deadlines and identify tasks that are due today or overdue.
- **Productivity Dashboard:** View total tasks, active tasks, completed tasks, and completion rate.
- **Automatic Saving:** Save tasks in the browser using `localStorage`.
- **Light and Dark Themes:** Switch between light and dark modes.
- **Responsive Design:** Use the interface on desktop and smaller screens.
- **Accessible Interface:** Includes keyboard-friendly controls and accessibility features.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and content |
| CSS3 | Styling, layout, themes, and responsive design |
| JavaScript (ES6+) | Task operations, search, filtering, sorting, and statistics |
| Browser Local Storage | Persist tasks and theme preferences in the current browser |

## 🚀 Getting Started

### Prerequisites

- A modern web browser, such as Google Chrome, Microsoft Edge, Firefox, or Safari.
- Git (optional, if you want to clone the repository).

### Option 1: Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start creating and organizing your tasks.

### Option 2: Clone with Git

```bash
git clone https://github.com/Naol-Ambisa/TaskManager.git
cd TaskManager
```

Then open `index.html` in your browser.

No Node.js installation, package installation, or backend server is required for the current version.

## 📖 How to Use

1. **Add a task:** Select the add-task button and enter the task details.
2. **Choose a category:** Categorize the task as Work, Personal, or Study.
3. **Set a due date:** Add a deadline when needed.
4. **Update tasks:** Edit task details whenever your plans change.
5. **Track completion:** Mark tasks as completed when finished.
6. **Search and sort:** Find tasks quickly and arrange them in a useful order.
7. **Monitor progress:** Use the dashboard statistics to review your productivity.
8. **Change appearance:** Switch between light and dark themes.

Your tasks and theme preference are stored in your browser's local storage.

## 💾 Data Storage

This project uses browser `localStorage` to save tasks and theme preferences.

**Important:** Data is stored locally in the browser rather than in a remote database. Tasks do not automatically synchronize across different browsers or devices. Clearing browser data may remove saved tasks, so avoid clearing local storage if you need to keep your data.

## 🔒 Security and Privacy

- The current version does not require a user account or server-side database.
- Task information is stored in the browser's local storage.
- Avoid entering sensitive or confidential information into the application.
